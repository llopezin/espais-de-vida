# Espais de vida

Welcome to Espais de vida. This project is built using Gatsby, a powerful and fast static site generator for React.

## Getting Started

To get started with the Homes Site project, you'll need to have Node.js (v16) and Gatsby CLI installed on your machine.

1. **Clone the repository**

```bash
git clone https://github.com/llopezin/espais-de-vida.git
```

2. **Install dependencies**

```bash
npm i
```

3. **Install dependencies**
```bash
npm run develop
```

4. **Build the project**

When you're ready to build the site for production, run:

```bash
npm run build
```
This will generate a public directory with your static site, ready to be deployed.

## Scripts

- `build`: Builds the site for production.
- `develop`: Starts the Gatsby development server.
- `format`: Formats code using Prettier.
- `start`: Alias for `develop`.
- `serve`: Serves the production build of the site.
- `clean`: Clears the Gatsby cache and public directories.
